Overview

TickGate sells market data for stock tokens on Robinhood Chain one call at a time. There are no API keys and no plans. Instead, every request goes through a toll gate built on HTTP 402 Payment Required: the first answer is a price, your agent pays it in a USD stablecoin, and the retry returns the data with an on-chain receipt.

  • Who it's for: AI agents and scripts that need a quote, a book or a candle, and shouldn't hold a long-lived secret.
  • What it costs: a few tenths of a cent to a cent per call (illustrative), shown in the quote before you pay.
  • Where it settles: Robinhood Chain, chain ID 4663. Gas is paid in ETH.

Quickstart

  1. Fund a wallet on Robinhood Chain with a little ETH for gas and a few dollars of the supported stablecoin.
  2. Call an endpoint with no headers. Expect 402.
  3. Read the quote, check it against your budget, and pay price to payTo.
  4. Repeat the same request with X-Payment set to your payment proof.
  5. Store receipt from the 200 response.
shell · sample
# 1. ask (API not live yet · pre-launch)
curl -i "https://api.tickgate.live/v1/price?symbol=STK·A"

# 2. after paying the quote, retry with proof
curl -i -H "X-Payment: <proof>" "https://api.tickgate.live/v1/price?symbol=STK·A"

The 402 flow

Every paid call is two HTTP requests with one on-chain payment in between. The gate never asks who you are, only whether this exact request has been paid for.

http · sample
GET /v1/price?symbol=STK·A
→ 402 Payment Required        { quote }

(agent pays quote.price to quote.payTo on chain 4663)

GET /v1/price?symbol=STK·A
X-Payment: <proof>
→ 200 OK                      { data, receipt }

See it animated on the protocol page, or run a simulated round trip on the home page.

Quote object

The body of every 402 response. A quote is tied to one request and can be paid once.

FieldTypeDescription
pricestringAmount to pay, decimal string in asset units.
assetstringThe USD stablecoin accepted for this call.
chainIdintAlways 4663 (Robinhood Chain).
payToaddressWhere the toll goes. Check it against your allowlist.
noncestringBinds a payment to this quote. Single use.
expiresInstringValidity window, 30s by default.
json · sample
{
  "price": "0.001",
  "asset": "USD stablecoin",
  "chainId": 4663,
  "payTo": "0x7A3c…9F02",
  "nonce": "q_8f21…",
  "expiresIn": "30s"
}

Paying a quote

Send exactly price of asset to payTo on chain 4663, carrying the quote's nonce so the gate can match it. Pay before expiresIn runs out; late payments don't unlock a stale quote.

TipCheck the quote before signing: price under your per-call cap, payTo on your allowlist, chainId equal to 4663.

X-Payment header

Retry the identical request (same method, path and query) with one extra header. Its value is the proof of payment: a reference to the settled transaction plus the quote nonce. The exact encoding will be published with the SDK.

http · sample
GET /v1/price?symbol=STK·A HTTP/1.1
Host: api.tickgate.live
X-Payment: 0x4b1e…(sample)

Receipts

Every 200 carries a receipt: the transaction hash, amount, endpoint and time. Keep it. It's how an operator reconciles agent spend line by line, and how a dispute gets settled.

json · sample
{
  "data": { "symbol": "STK·A", "last": "182.40" },
  "receipt": {
    "tx": "0x9f4e…c2a1",
    "amount": "0.001",
    "endpoint": "/v1/price?symbol=STK·A",
    "chainId": 4663,
    "sample": true
  }
}

Budgets and rules

Because payment is the only authorization, budgets live with the agent. The SDK planned for launch checks four rules before it signs anything. If any fails, it doesn't pay.

RuleWhat it stops
Per-call capA single quote above your ceiling.
Daily capSpend past the day's budget.
AllowlistEndpoints or pay-to addresses you didn't approve.
Kill switchEverything, for one agent or the whole fleet.

Errors

Errors are JSON with a stable code and a human message. Planned codes:

StatusCodeMeaning
400bad_requestMissing or invalid parameter.
402payment_requiredUnpaid request. Body is a fresh quote.
402quote_expiredProof matched a quote older than its window. Ask again.
409quote_usedThat nonce already unlocked a response.
422payment_mismatchWrong amount, asset, chain or pay-to.
429slow_downToo many unpaid requests from one client.
503gate_closedMaintenance or upstream data unavailable. You weren't charged.

Limits and expiry

  • Quotes expire after 30 seconds and are single use.
  • Batch price calls accept up to 20 symbols for one toll.
  • Unpaid requests may be rate limited per client to keep the gate responsive.
  • All limits are draft values and will be confirmed at launch.

SDK pseudo-code

The SDK ships at launch. Until then, this is the shape of it.

// pseudo-code · SDK at launch · API not live yet
import { TickGate } from "tickgate";

const gate = new TickGate({
  wallet,                          // your Robinhood Chain wallet
  caps: { perCall: "0.01", daily: "5.00" },
  allow: ["/v1/price", "/v1/depth"],
});

const { data, receipt } = await gate.get("/v1/price", { symbol: "STK·A" });
console.log(data.last, receipt.tx);

from tickgate import TickGate

gate = TickGate(

Security notes

  • Give each agent its own wallet with only what it needs to spend. Top it up; don't overfund it.
  • Always verify chainId and payTo. Never pay a quote that arrived from anywhere but the gate you called.
  • The only official site is tickgate.live and the only official X account is @ticketgaterh.

Glossary

TollThe price of one call, paid per request.
GateThe TickGate API, which answers 402 until paid.
QuoteA single-use price for one request, valid for 30 seconds.
ProofThe X-Payment value that points at your settled payment.
ReceiptThe on-chain record returned with your data.
Stock tokenA tokenized stock on Robinhood Chain. Availability may be restricted where you live.
