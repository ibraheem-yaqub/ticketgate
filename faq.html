FAQ

Questions atthe counter.

Short answers about the gate, the toll, the data and the token. Can't find yours? Ask @ticketgaterh on X.

Robinhood Chain
GeneralWhat is TickGate?
Pay-per-call market data for AI agents on Robinhood Chain. Your agent pays a few cents in stablecoin per request and gets the data plus an on-chain receipt. No API keys, no plans.
GeneralIs it live?
Not yet. This is a pre-launch preview. api.tickgate.live is not live, and all data on this site is sample data. See the roadmap.
GeneralIs this affiliated with Robinhood?
No. TickGate is an independent project built for Robinhood Chain. It is not affiliated with Robinhood Markets, Inc.
GeneralWhere do I get official news?
Only on tickgate.live and on X at @ticketgaterh.
PayingWhat is HTTP 402?
402 Payment Required is a status code that has been in the HTTP spec since the 1990s, reserved for payments. TickGate uses it as intended: the server replies 402 with a price quote, the client pays, then retries with proof of payment.
PayingWhich chain?
Robinhood Chain, an Arbitrum Orbit L2 (chain ID 4663). Gas is paid in ETH; calls are priced in a USD stablecoin.
PayingHow much does a call cost?
Illustrative prices run from $0.001 to $0.01 per call depending on the route. The real price is always in the 402 quote before your agent pays.
PayingWhat if a quote expires?
Quotes last 30 seconds and can be used once. If it expires, ask again for a fresh quote. Don't pay an expired one.
PayingDo I need the $TGATE token to pay?
No. Every call is paid in a USD stablecoin. $TGATE is not required to use the API.
AgentsDo I need an API key?
No. Payment is the authorization. No keys, no accounts, no monthly plans.
AgentsHow do I stop an agent overspending?
The SDK planned for launch checks a per-call cap, a daily cap, an endpoint allowlist and a kill switch before it signs. Also give each agent its own small wallet. See budgets.
AgentsIs there an SDK?
Not yet. JavaScript and Python SDKs are planned. The docs show the intended shape in pseudo-code.
DataWhat data is available?
Nine planned routes for stock tokens on Robinhood Chain: price, depth and history. See the endpoints page.
DataAre the prices on this site real?
No. Every price, chart, receipt and symbol on this site is sample data, marked SAMPLE, SIMULATED or illustrative.
DataCan I use it where I live?
Stock tokens may be restricted in your jurisdiction. Check local rules before using the data or trading.
TokenWhat is $TGATE?
The community token for the TickGate project. It isn't required to use the API, and nothing here is financial advice or a promise of value. See the token page.
TokenWhat's the contract address?
Announced at launch, only on tickgate.live and @ticketgaterh. Anyone sending you a CA before that is not us.
