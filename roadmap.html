Roadmap

From previewto mainnet.

Five phases, in order. We mark what's done, what's being built and what's planned. No dates until we can keep them.

Robinhood ChainDoneIn progressPlanned
Phase 0 · PreviewDone

The booth goes up.

  • tickgate.live with a simulated 402 round trip
  • Brand, gate mark and brand kit
  • Draft docs and endpoint list
Phase 1 · SpecIn progress

Write down the toll.

  • Final quote, X-Payment and receipt formats
  • Error codes and limits confirmed
  • Early-access builders give feedback
Phase 2 · SandboxPlanned

A gate you can test.

  • Sandbox endpoints with test funds
  • SDK alpha for JavaScript and Python
  • Budgets, allowlists and kill switch in the SDK
Phase 3 · LaunchPlanned

The gate opens.

  • api.tickgate.live live on Robinhood Chain
  • Price, depth and history routes
  • On-chain receipts for every paid call
Phase 4 · More lanesPlanned

Widen the road.

  • More endpoints, shaped by what agents actually call
  • Usage dashboard for receipts and spend
  • Streaming options, if demand is there
NoteRoadmap items are plans, not promises. Order and scope may change. Follow @ticketgaterh for updates.
